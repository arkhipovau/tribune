# UDF — дизайн-система Tribune

Атомарная структура по образцу Design-Culture. Подключение: Vite собирает бандл на страницу.

| Слой | Префикс | Папка | Роль |
|---|---|---|---|
| Токены | — | `tokens/` | цвета, типографика, сетка, движение (CSS-переменные) |
| Кварки | `q-` | `quarks/` | шрифты, иконки |
| База | — | `base/` | сброс стилей |
| Атомы | `a-` | `atoms/` | кнопки, пилюли, ссылки, подписи |
| Молекулы | `m-` | `molecules/` | карточки, шаги, плитки, шторка |
| Организмы | `o-` | `organisms/` | секции страниц |
| Суперорганизмы | `s-` | `superorganisms/` | шапка, футер, переходы |
| Бандлы | — | `bundles/` | точки входа страниц |

Правила: одна папка на компонент `{слой}/{имя}/{префикс}-{имя}.css|js` + `README.md`; состояния `.is-*`; цвета, размеры и скругления — через токены.
